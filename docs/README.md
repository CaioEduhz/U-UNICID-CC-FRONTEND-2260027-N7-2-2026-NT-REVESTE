## Sobre o projeto

O **Trocaverde** é uma proposta de rede comunitária para troca e reaproveitamento de roupas. O projeto busca incentivar o consumo consciente, prolongar a vida útil das peças e conscientizar sobre os impactos ambientais do descarte têxtil e da moda rápida (*fast fashion*).

**Slogan:** “Troque roupas, não o planeta.”

> **Importante:** o Trocaverde é um projeto acadêmico. Os números de impacto e as informações sobre pontos físicos apresentados no site são ilustrativos/fictícios e não representam resultados de uma operação real.

## Objetivo

Desenvolver um site informativo, responsivo e acessível, composto por dez páginas interligadas, que apresente a proposta do Trocaverde e conteúdos sobre moda circular, inclusão e sustentabilidade. Na entrega A2, o projeto também deve atender aos requisitos de JavaScript definidos na atividade.

## Como executar localmente

1. Baixe ou clone o repositório.
2. Mantenha a estrutura de pastas e os caminhos relativos dos arquivos.
3. Abra `index.html` em um navegador ou utilize a extensão Live Server no Visual Studio Code.
4. Para conferir a versão final, compare os arquivos locais com a versão publicada.

A estrutura prevista inclui os dez arquivos HTML, a pasta `css/`, a pasta `js/`, os recursos de mídia e a pasta `docs/`. Confira se todos esses itens estão presentes no repositório antes da entrega.
