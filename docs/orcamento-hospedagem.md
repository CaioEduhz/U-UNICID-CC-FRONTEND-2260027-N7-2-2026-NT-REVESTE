> Valores são **estimativas de referência**, não cotações. Preços, créditos, limites dos planos e condições de uso podem mudar. Conferir os valores e as regras nos sites oficiais antes de contratar.

## Justificativa

O Trocaverde é um site estático desenvolvido com **HTML, CSS e JavaScript**. Para a publicação da versão atual, a **Opção A (GitHub Pages)** continua sendo a alternativa gratuita mais direta. A **Opção C (Vercel)** também oferece hospedagem gratuita para uso não comercial.

A **Opção B (Railway)** é uma alternativa interessante caso o projeto cresça e precise de maior controle sobre o servidor, como configurações de NGINX, redirecionamentos e cabeçalhos de cache, ou caso futuramente seja necessário hospedar um backend ou banco de dados. O plano Hobby é apresentado no comparativo por US$ 5 mensais, com US$ 5 em créditos de uso; o consumo acima desse valor pode gerar cobrança adicional.

O Railway também permite integração com o GitHub para automatizar a publicação a cada `push`, após a configuração do serviço. Para o endereço do projeto, **trocaverde.com.br** é a opção mais familiar para o público brasileiro, desde que esteja disponível.

Se a equipe optar por uma hospedagem paga ou migrar de plataforma, deverá conferir previamente os preços, limites, regras de uso comercial e condições de renovação. Como o tema é sustentabilidade, também recomendamos verificar se o fornecedor divulga metas ou iniciativas relacionadas ao uso de energia renovável.
